# Walkable home and movable furniture

Entering an ashore interior selected a newly allocated empty crew array on every
Zustand snapshot. React kept rendering until its update-depth limit (error 185),
leaving the game blank. The crew selector now returns the existing roster or a
stable undefined value. The empty display fallback is applied after selection.
This shared fix also covers shore shops, neighbour previews and empty ship cabins.
Canvas failures now offer a visible explanation and an exit instead of a blank
colour panel.

The player's cottage now opens directly as a full-screen walkable room. It has
wooden floorboards, curtained windows, a hearth, patchwork bedding, a tea table,
a cushioned chair, a dresser, a woven rug, a potted fern and a mushroom lamp.
The music box moves with its table, and recovered keepsakes remain on the wall
shelf. Tap the floor, use the direction pad, or use arrows/WASD to walk. The front
door and Leave home both return outdoors. Home comforts contains tea, paid home
upgrades, repairs and the shared aquarium.

Arrange furniture freezes character movement while editing. Choose an item from
the list or tap visible furniture, then tap open floor or use the movement buttons.
Coordinates snap to quarter-unit steps. Pieces rotate by 90 degrees and can be
stored and placed again without fees. Rugs are walkable and may sit under solid
furniture. The hearth and windows are structural fixtures. The furniture shop
adds beds, tables, chairs, sofas, dressers, bookshelves, lamps, plants and rugs.
Extra copies cost base price multiplied by 1.35 for each already owned copy of
that kind. Purchases go to storage; total ownership is capped at 32 pieces.

Placement checks the rotated footprint against room bounds, solid furniture,
hearth and reserved front-door space. It also verifies a route from the door to
the player and through the room, rejecting placements that trap the character.
Walking uses the same live layout as placement, with stored items removed from
collision. A stale walking path is cleared if the live layout obstructs it.
Editor selections and walking state are transient; furniture ownership, storage,
position and rotation are persistent. Rearranging does not teleport the player.

The outdoor renderer is released while an interior is open. Navigation hooks and
outdoor coordinates remain mounted, so returning preserves location without
running two game canvases on a phone. The home now has its own room view rather
than a preview above a service list. Other public rooms retain their services.

Save version 21 adds homeRoom. Existing homes receive starter furniture. Invalid
or overlapping saved pieces are retained in storage, with unknown types and
duplicate IDs ignored. Furniture purchases and layout mutations require a safe
visit to the player's own cottage; neighbour and ship interiors cannot change it.
Android versionCode 18 / versionName 0.1.17-cozy-home.

Validation:

- The pre-fix APK reproduced React error 185 when entering the cottage ashore.
- check:home-room covers starter routes, live collisions, rotation, storage,
  overlaps, door/player safety, rug layering, prices, unsafe states, legacy saves,
  corrupt layouts, bounded inventory and fresh-game reset.
- The complete automated suite includes all prior ocean, town, fishing and combat
  checks, plus updated cottage route fixtures for the new furniture positions.
- test:home-browser is an optional Playwright regression against built APK assets.
  It checks actual floor walking and furniture selection/placement, rotation,
  storage, paid delivery, phone/landscape bounds, home comforts, exit/re-entry,
  reload persistence, one active game renderer and shore shop previews.

For the browser test, install playwright-core and a compatible Chromium, build
the APK, then run CHROMIUM_PATH=/path/to/chromium npm run test:home-browser.
PLAYWRIGHT_MODULE optionally selects another installed module path; HOME_SCREENSHOT
sets the screenshot output. Browser checks do not measure physical-device FPS.
